## Чеклист ревью

1. **Границы объёма:** нет реализации из §1.2; решения §20 не нарушены.
2. **Расчётное ядро:** формулы только в `calc/engine.py` как чистые функции; нигде нет `float` в деньгах; ROUND_HALF_UP; `order_range` не используется; дефициты независимы по фитам; строгий scope.
3. **ESI:** нет вызовов ESI из `views/` и веб-запросов; батчинг, лимиты (`X-ESI-Error-Limit-Remain`), ретраи с backoff; перезапись кэша атомарна (одна транзакция на источник).
4. **Celery:** guard-интервалы из настроек; `trigger=manual` не отправляет уведомления о дефиците; дедупликация по state-hash и cooldown; идемпотентность задач; блокировка ручного запуска.
5. **Права:** все view — `login_required` + `has_view`/`has_edit`; webhook URL скрыт от не-`_edit`; `SyncRun` только в admin.
6. **Качество:** нет `print`, N+1, запросов ESI в цикле по компонентам; логгер `marketmonitoring`; таймауты на всех внешних вызовах; имена — английские, комментарии публичных функций — русские.
7. **Тесты:** новые изменения покрыты группами §18; тесты без сети.
