## Обязательные группы (§18 ТЗ)

1. **EFT-парсер** (`test_eft_parser.py`): en/ru экспорт, Empty-слоты, `xN` у дронов и зарядов, заряды через запятую, суммирование дубликатов, нераспознанная строка → ошибки с номерами, нераспознанный корпус → отказ.
2. **Расчётное ядро** (`test_calc_engine.py`): эталонный пример §6.11 **целиком** (K, узкие места, D_i, unit, cost, Total); один лот ≥ D; несколько лотов; `NOT_COVERED` и `shortfall`; оверпрайс на пороге и чуть выше; `τ=0`.
3. **Scope** (`test_orderbook.py`): `station` не учитывает систему/регион; `system`/`region` — NPC-станции + только включённые структуры; per-component override.
4. **Статусы**: `NO_DATA` (нет данных / протухли), `HULL_MISSING`, `OK` при K=N.
5. **Провайдеры** (`test_providers.py`): выбор по приоритету; 403 → cooldown 60 мин и переход к следующему; 3 сбоя → `disabled` + алерт; успех сбрасывает счётчик; `no_provider` → `NO_DATA`.
6. **Задачи** (`test_tasks.py`): `manual` не вызывает `notify_deficit`, `beat` вызывает; дедупликация по хэшу и 2-часовому кулдауну; атомарная перезапись кэша; блокировка ручного запуска → 409.
7. **Права** (`test_views_permissions.py`): `_view` не создаёт/не правит, не видит настройки и admin-лог; `_edit` всё, кроме `SyncRun`.
8. **Экспорт** (`test_export.py`): multibuy только при D_i>0, английские имена, табы; CSV-заголовки; сумма `cost` = `Fit.total_cost`.

## Правила

- Тесты выполняются **без сети**: ESI и webhook — через `responses`/`unittest.mock`.
- Эталонные числа §6.11 перепроверять точно: Total = 1 269 912 500 и т.д.
- Денежные значения сравнивать `Decimal`, не строками и не float.
- Перед сдачей: `python manage.py makemigrations --check`, полный прогон тестов, линт (black/isort, line-length 120).
