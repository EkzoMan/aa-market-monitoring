# 03. Мастер создания/правки фита + удаление

Роуты: `fit_create` / `fit_update` (edit), `fit_delete` (edit). Шаблоны:
`fit_form.html`, `fit_delete.html`.

Мастер — 3 шага на одной странице (пошаговый wizard без JS-фреймворка: шаги
разграничены секциями, «Разобрать» — POST с серверным парсингом и повторным
рендером той же страницы в состоянии предпросмотра).

## Вайрфрейм — шаг 1: EFT

```
┌────────────────────────────────────────────────────────────────┐
│ ← Dashboard │ New fit (step 1 of 3: paste EFT)                 │
├────────────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ textarea (rows=10, font-monospace, small)                  │ │
│ │ [My Curse, Curse]                                          │ │
│ │ Nano-Integrator II x3                                      │ │
│ │ …                                                          │ │
│ └────────────────────────────────────────────────────────────┘ │
│ ⓘ Parser accepts EFT names in any SDE language.               │
│                                   [Parse →]  (btn-primary)    │
└────────────────────────────────────────────────────────────────┘
```

## Шаг 2/3: предпросмотр разбора + поля

```
┌────────────────────────────────────────────────────────────────┐
│ ← Dashboard │ New fit (steps 2–3: preview & parameters)         │
├────────────────────────────────────────────────────────────────┤
│ PARSED COMPONENTS (card)                    (edit) [+ Add line] │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ Component ▾(SDE-search)  Qty per fit  Scope ▾  HULL  [🗑]   │ │
│ │ █ Curse                  1              Station ✓           │ │
│ │   Nano-Integrator II     3              Region ▾            │ │
│ │   …                      [n]  (number input)                │ │
│ └────────────────────────────────────────────────────────────┘ │
│ ⓘ HULL row: scope of the hull is the fit scope.                │
├────────────────────────────────────────────────────────────────┤
│ PARAMETERS (card)                                              │
│  Name: [__________]   Target qty N: [3]   Scope: [Region ▾]    │
├────────────────────────────────────────────────────────────────┤
│                              [Cancel]  [Save fit]              │
└────────────────────────────────────────────────────────────────┘
```

## Правила

- **Ошибки парсинга** (`alert-danger` над textarea): перечень непонятных строк
  с номерами; textarea сохраняет введённое (пере-рендер с предыдущим содержимым).
- **Компонентная таблица предпросмотра:** каждое имя компонента — с SDE-селектором
  (поиск по имени, `<input list>` + datalist или select — реализация на усмотрение
  разработчика; дизайн: имя + scope в одной строке, компактно). Количество —
  `form-control` числовой, ширина 80px, right.
- **Добавить/удалить строку** — HTML-формы (POST «add row» / submit с префиксами),
  без клиентского JS-состояния.
- **Overrides scope** — select «Station / Region» на строке.
- **Отмена:** ссылка «Cancel» → дашборд; данные не сохраняются.
- **Правка фита:** та же страница, textarea не обязательна (состав правится таблицей).
- CSRF на обеих формах (два `<form>`, каждый с токеном).

## Удаление фита (`fit_delete`) — confirm-экран

```
┌────────────────────────────────────────────────────────────────┐
│ ⚠ Delete fit “My Curse X-type”?                                │
│ This will remove the fit and its component lines.              │
│ The hull/component SDE types and locations are not deleted.    │
│        [Cancel]  [🗑 Delete — cannot be undone] (btn-danger)    │
└────────────────────────────────────────────────────────────────┘
```

- Отдельный экран (существующий `fit_delete.html`), не JS-модал: после редиректа
  confirm-экран переживает обновления поллинга.
- Кнопка подтверждения — `btn-danger`, текст с явным «cannot be undone».
