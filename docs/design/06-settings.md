# 06. Настройки

Роут: `settings` (edit). Шаблон: `settings.html`. Содержимое — §10 ТЗ + webhook + провайдеры.

│  Orders sync interval h:  [ 6 ]   Structures sync interval h: [ 24 ]          │

## Правила

- **Вебхук:** URL никогда не рендерится в шаблон для пользователей без `_edit`;
  в input использовать `type="password"`-подобное скрытие + «Show» toggle
  (по умолчанию скрыт). Страница целиком edit — правило выполнено конструкцией,
  но дизайн фиксирует: значение не вставлять в DOM как текст.
- Числовые поля: `type="number"`, `.mm-num`, подписи «%» / «ISK» через `input-group-text`.
- Провайдеры: приоритет — кнопки ↑/↓ (POST-формы, без drag-n-drop JS); статус синка —
  чип как на Локациях; вкл/выкл — `form-switch` в форме.
- Валидация серверная: ошибки — `is-invalid` + `invalid-feedback` под полем;
  успешное сохранение — toast «Saved» (или `messages` framework → alert-success).
- CSRF на каждой форме; при нескольких `<form>` — токен в каждой.
